# Project screenshots

Real screenshots of Omar's projects, used by the "Selected work" section of `index.html`.

- **Format:** WebP, ~1600×1000 for desktop views (phones: 800×1600 portrait), under ~250 KB each.
- **Naming:** `<project-slug>-01.webp`, `-02.webp` … (e.g. `resume-needed-01.webp`).
- **HTML:** always set `width`/`height` (prevents layout shift), `loading="lazy"`, `decoding="async"`
  and a meaningful Arabic `alt`.
- Only public pages — never screens behind a login or containing user data.

Current set: resume-needed, teamstein, hamesh (featured), zad (phone screens + icon/feature graphic),
onecar and hizzar (spare shots, for when they get promoted to featured projects).
